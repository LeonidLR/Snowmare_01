# Audio Events Registry - Operation: Cold Silence (`EVENTS.md`)

- **Status:** Draft v1 (Gemini, `033`) -> pending Claude (`audio-director`) & Designer sign-off.
- **Conforms to:** [SOUND_BIBLE.md](SOUND_BIBLE.md) (v0.1 mix & accessibility rules) & [AUDIO_PROCESS.md](AUDIO_PROCESS.md) table format.
- **Scale rules:**
  - `bus`: `Music`, `VO`, `SFX`, `UI`, `Ambient` (routed to `Master` limiter `-16 LUFS / -1 dBTP`).
  - `priority (1-5)` (`SOUND_BIBLE.md §3`): `1` = player damage & critical warnings, `2` = player actions, `3` = enemy actions, `4` = UI, `5` = environment / ambient & music underscore.
  - `file:line`: verified in `Source/CodexTactics/` and `Content/Data/` (planned hooks marked `[Planned]` with nearest owning system).
