# Project audit: cleanup, size and speed (2026-10-11, read-only)

**Scope.** The user asked where to start cleaning up, and where code can be smaller and a little faster. Nothing in the
repo was changed: no build, no commandlet, no asset save. The only new file is this report.

**Method.**
- **Code:** static reading of `Source/`, plus small scratchpad scripts that measured functions, built the include graph
  and found cost markers inside the per-frame functions.
- **Content:** a static `/Game/...` reference scan of all 2,321 `.uasset` / `.umap` files. The roots are
  `Content/Maps/*`, `/Game` paths in runtime C++ (comments excluded), `Config/*.ini` and `Content/Data/**/*.json`.
  - The scan gives a lower and an upper bound. FName number suffixes (`X_1` is stored as `X` + 1) make some links
    ambiguous.
  - A headless asset-registry commandlet was not used. A `UnrealEditor-Cmd` Python commandlet already had the main
    project open, and agents were running smokes in both worktrees.
- **Tests:** smoke timings and failures come from the `Saved/Logs/Smoke-*.log` files of all three checkouts.
