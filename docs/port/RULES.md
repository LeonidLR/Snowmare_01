# Правила работы CodexTactics

Черновик на 23 ноября 2026. Основание — решения дизайнера, верх [TANDEM.md](TANDEM.md) и сообщения Lead.

1. Рабочая версия игры — Unreal 5.8.2. Godot доступен для чтения как архив. Баланс правим в Unreal.
2. Перед задачей прочитай `CLAUDE.md`, верх `HANDOFF.md`, правила своей роли и свежие сообщения Lead.
3. Lead распределяет задачи, проверяет ветки, вливает и пушит. Делегированные задачи идут Codex. Gemini на паузе. Для Grok с 24 ноября запланирована проба по gameplay C++.
4. Lead работает без своих субагентов. Короткое ревью Fable возможно по отдельному согласию дизайнера.
5. Бери по одной задаче из очереди. Один небольшой результат — одна ветка и один worktree в `C:/Work/Lanes`. Lead убирает копию после вливания, предварительно снимая junctions.
6. Codex работает в своей копии и передаёт коммиты Lead. Только Lead вливает или пушит. Карты, `.uasset`, Config, VFX и несохранённую в Git работу дизайнера бережём. Любое исключение требует прямого указания дизайнера.
7. Подтверди диагноз до правки конкретными строками лога, числами или `файл:строка`. Существующие проверки сохраняй.
8. Задавай `CODEX_AGENT` для своей роли. Добавляй файлы явными путями. Делай небольшие Conventional Commits с номером задачи в теле. Перед последним коммитом Codex нужен TypeSafe `--audit-diff --agent codex` со статусом PASS.
9. Ревью проводят до вливания, по одной ветке. Lead собирает 2–3 проверенные ветки в один пакет.
10. Перед вливанием Lead проверяет командную строку GUI Unreal для пути `main`. При открытом редакторе gate останавливается. Перед merge сохраняет изменённые файлы дизайнера и сверяет SHA-256. При конфликте останавливается.
11. Сборка нужна при изменениях `Source/` или `*.uproject`. Lead запускает `test.ps1 -Smart` после вливания и полный набор ночью. После принятия 060 для этого служит merge gate.
12. Смоуки берём из `Scripts/test_map.json` по изменённым файлам и запускаем только на worker. Codex также отправляет тяжёлые прогоны на worker. Используй слот 1, полные имена команд, `-ShareMachine -ShipHead` и число jobs из задания.
13. Оставляем Kit-витрину, Depot X6, FrozenLake, VehicleTest и MainMenu. Архив старых карт ведёт Lead. Тренировка, боты и A/B идут на X6. Сначала проверяем навыки боя на открытом пространстве.
14. Общайся по-русски. В отчёте укажи изменения с `файл:строка`, фактический результат тестов и пропущенные проверки. В AgentChat отправь одну строку `FINISH` с хешем. О блокере сообщи сразу.
15. При 10% остатка остановись, закоммить текущее состояние, дополни отчёт и напиши в `<agent>-limit` состояние, хеш, следующий шаг и время сброса. До полного сброса только жди через AgentChat.
