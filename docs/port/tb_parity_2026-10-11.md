# Real time vs turn-based damage parity (2026-10-11)

Audit `audit_2026-10-11.md` area 2 / top-10 #8. The **double application** bugs are fixed (commit «fix(tactics): each
turn-based damage modifier applies once»); the **number mismatches** below are left unchanged for the user to choose.

## Fixed (each modifier now applies once)

| Path | Before | Now | Godot archive |
|---|---|---|---|
| TB squad shot on an enemy | grid flat armour (`SquadAttackDamage`) **and** `UHealthComponent` % armour | grid flat armour only (`TurnBasedRules::SquadShotArmorPenetration` = 1 on the spec); affinity / downed x1.33 once | both (`turn_based_combat_manager.gd:1186` flat, then `enemy_base.gd take_damage` %) — the same double cut |
| TB barrel / mine blast on an operative | grid stance factor (0.70 / 0.50) **and** real-time stance defence (0.75 / 0.50), + heavy-hit knockdown roll | grid stance factor once (`OperativeHitRules` `GridBlast`: fortitude + downed x1.33, no cover, no heavy-hit knockdown; `NotifyExplosion` still floors him) | both (`_detonate_barrel:2898` / `_detonate_mine:2987` pre-multiply, then `player.gd take_damage` x `stance_defense_multiplier`) — the same double factor |
| TB blast dodge | luck dodge (luck x 0.4 %) | **kept** (Godot had it) — `TurnBlastDeathSmoke` pins the roll, no more flake | yes: `take_damage(final_dmg)` without `bypass_avoidance` |
