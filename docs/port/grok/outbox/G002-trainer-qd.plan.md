# G002 план — метрики поведения и архив MAP-Elites

Кода в этом коммите нет. Ветка `grok/G002-trainer-qd` от main `7705adf6`. Роутер: level 4 | grok-4.7 (основная сессия; confidence 0.53, порог 0.60, route false) | план записан, тренер не менялся.

## Что есть сейчас

`Scripts/Trainer/nighttrainer`: один скаляр на кандидата (`fitness.py`), отбор турниром (`evolution.next_generation`), соперник — текущий чемпион (`evaluation.matches`, два джоба `champion`, бот выключен). Поведение в результате арены не читается. Из-за этого ночь уже дважды выучила «спрятаться» (pmc-v2, pmc-v4): скаляр платит за выживание, а не за разный стиль.

`docs/design/TACTICAL_MAP.md` §4 задаёт список метрик раунда. C++ (P3) их ещё не пишет. Тренер собирается сейчас, на схеме и на моке.

## Что сделаю

Только `Scripts/Trainer/**` и `docs/port/grok/outbox/G002-*`. `pmc_commander.json`, C++ и `Content/` не трогаю.

1. Схема `docs/port/grok/outbox/G002-arena-behaviour-schema.md`: объект `behaviour` в раунде (`codex.pmc_arena/1`), у каждой метрики имя, единица, диапазон, направление. Список §4 плюс `moves` (ось подвижности из задачи). Плоский и богатый вид. Нет поля — нули, старый результат арены не падает.
2. `nighttrainer/adapter.py` читает `behaviour` (или `sides.A.behaviour`) и всегда кладёт полный словарь. Чужая метрика не обязательна.
3. `nighttrainer/qd.py`: MAP-Elites. Оси, корзины и файл архива — `trainer_config.json` → `qd`. Клетка хранит лучшие веса. Качество клетки = тот же скаляр `fitness.py`. Вставка только если скаляр строго выше. Родители следующей популяции — равномерно из заполненных клеток. Пустой архив — как сейчас, от базовых весов.
4. Переключатель `search.mode`: `qd` (новый прогон по умолчанию) или `ga` (старый турнир, A/B). Режим снимка в `run.json`, возобновление его не меняет.
5. Лига при `qd`: один соперник из пула архива (пока архив пуст — текущий чемпион) и один джоб `bot` (тот же соперник, что уже есть). Сиды поколения общие для всех кандидатов, как сейчас.
6. Утренний отчёт: секция архива — клеток занято / всего, лучший в клетке, значения поведения, короткая подпись клетки (aggressive flanker / patient ambusher / suppress-and-push / mixed). `ga` пишет, что архив выключен.
7. Мок (`mock_arena.py`) пишет `behaviour`, чтобы три поколения разъехались по клеткам. Старые фикстуры без поля остаются проверкой нулей.

Скаляр не переписываю. Число джобов на кандидата остаётся два, чтобы старые проверки цикла не потеряли смысл.
