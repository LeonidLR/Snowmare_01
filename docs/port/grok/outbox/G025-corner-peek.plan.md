## Часть 1 — Shift-click поворачивает конус

Диагноз по коду, до правки поведения.

На углу peek включён (`WantsCornerHold` для ручного peek, `BeginCornerAim`). `GetPeekSight` для `CornerLean` ставит направление `CornerAimDirection` плюс `GetAppliedAimYaw()`. `GetAppliedAimYaw` — это `AimYaw` анимации, а `UpdateAimOffset` берёт точку только из `GetAimTargetPoint` (последний выстрел или боевая цель). Shift-click пишет `ManualLookPoint` (`CodexTacticsPlayerControllerOrders.cpp`, «LOOK ANCHOR») и в укрытии дальше не используется: `UpdateCombatFacing` при `bInCover` сразу возвращается, рысканье актёра держит стену.

Конус на экране и `CanOperativeSee` оба идут через `GetPeekSight`. Полуугол peek — 45°. Враг на 50° влево от штатного прицела угла лежит вне конуса, хотя игрок уже смотрит туда. Пока его не видно, боевой цели нет, `AimYaw` остаётся 0, конус не двигается.

Правило: пока держится ручной взгляд, центр peek-конуса (и обзор из той же точки) смотрит на эту точку по короткой дуге. Поворот анимации при этом не прибавляется — иначе конус проскакивает мимо взгляда. Без взгляда остаётся сегодняшний прицел угла плюс `AimYaw`. Тот же поворот для взгляда поверх низкой стены; без взгляда её направление не меняется. Стена по-прежнему режет луч (`HasClearSight`). Лимит AO — следующий шаг, на зрение его не вешаю.

Юнит: `CodexTactics.Combat.Sight.PeekLookCone`. Враг на 50° вне штатного конуса; после взгляда туда он внутри; сложение со старым `AimYaw` снова выносит его наружу.

Сборка локально, `Scripts/build.ps1` без `-Remote`.
