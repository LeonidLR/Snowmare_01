У четырёх модулей стоит `PCHUsage = UseExplicitOrSharedPCHs` в их `*.Build.cs`. Обычный запуск оставляет adaptive unity включённым. `Scripts/build.ps1:55–83` использует полный unity и no-unity как отдельные режимы проверки и специально инвалидирует makefile. Они не должны добавляться к обычному merge. В сохранённом логе нет компиляции PCH, на основании этого прогона ускорение от смены PCH оценить нельзя.
