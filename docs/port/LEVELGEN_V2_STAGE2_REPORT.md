# Генератор уровней v2 — этап 2: типы кварталов, замки, расширение ×2/×4/×6, старт + цели (доска 066)

Ветка `feat/levelgen-v2-stage2` (от main 2091b949). Только TypeScript (Training Ground) + новый конфиг
`Content/Data/LevelGen/levelgen_v2.json`. C++, `.umap`, `.uasset`, `Config/*.ini` не тронуты; существующие карты дизайнера
(`Content/Data/LevelJson/**`, `Content/Data/LevelGen/accepted/**`) только читаются, тесты пишут во временную папку.

## Что работает

### A. Перегенерация зоны меняет ТИП кварталов (главная жалоба)
- Карта разбита на кварталы (lots): 15 регионов классической грамматики Depot (`generateLayoutWithLots`, раскладка байт в байт
  та же) + кварталы расширения. Тип каждого хранится в JSON карты: `regen.blocks` (версия блока `regen` теперь 2, файлы v1 грузятся).
- Квартал, чей центр внутри зоны, получает ДРУГОЙ тип из каталога (12 серых сет-пьес, `src/levelgen/blockTemplates.ts`: двор с
  одним входом, цех, склад с двором, контора, двухэтажка, глухой фасад, вышка с лестницей, резервуары, свалка, огороженная
  площадка, котельный двор, площадь). Выбор — взвешенный по seed клика (веса и минимальные размеры — в `levelgen_v2.json`),
  квартал заменяется целиком; двери и ворота смотрят на ближайшую улицу. Маршруты заходят в новый квартал (дверь / ворота /
  лестница на крышу), проверка маршрута и повторы с новым seed — как на этапе 1.
- Закреплённый квартал и кварталы старта/финиша основного маршрута тип не меняют (`anchored`). Квартал, куда не помещается ни один
  другой тип (узкая площадка у склада 24×6 м), перерисовывается по-старому и показан в отчёте.
- Флажок «новые типы кварталов» выключает это (режим этапа 1 — только перестановка).
- Скриншоты: `docs/port/screenshots/071-levelgen-reroll-before.png` (зона на северо-западе, голубым пунктиром — 5 кварталов,
  которые сменят тип) и `071-levelgen-reroll-after.png` (seed 303: фасад → контора, вышка → свалка, двор → огороженная
  площадка, цех → резервуары, котельный двор → огороженная площадка; маршрут проходим).

### B. Открытые пункты этапа 1
- Дыры в заборах на границе зоны: кольцо забора (`F_<имя>_<N|S|E|W>_<k>`) и тупиковый переулок теперь — одна группа; кольцо
  берётся целиком или целиком остаётся; если новое кольцо не ставится, старое восстанавливается. Забор может касаться ящика.
- Отдельная кнопка «Сохранить замки» (`POST /api/levelgen/save-locks`): закреплённые районы (многоугольники) пишутся в JSON
  принятой карты — меняется только `regen.locks`, сама карта остаётся как принята; если карта ещё не принята — вся раскладка
  сохраняется черновиком в `Saved/TrainingGround/levelgen/<имя>.json`.

### C. Расширение карты ×2 / ×4 / ×6 по площади (`src/levelgen/expand.ts`)
- Холст = базовый размер × √N: Depot 177×124 → ×2 250×175, ×4 354×248, ×6 434×304 м. Старая карта остаётся в центре: её
  UE-координаты не меняются, все старые объекты и закреплённые районы байт в байт те же.
- Новая площадь генерируется тем же механизмом кварталов: дороги, выходящие на край старой карты (западная улица, северная вдоль
  канала), продлеваются до нового края; кольцевая улица вокруг старой карты; сетка улиц каждые ~46 м (каждая улица кончается
  на другой улице или на краю — тупиков нет); канал продлён до обоих новых краёв с подпорными стенами и мостами там, где его
  пересекает новая улица; клетки между улицами — кварталы из каталога (сохраняются в `regen.blocks`, их можно перегенерировать
  зоной), барьеры на улицах, точки появления врагов на концах улиц у края.
- Проём на шве: старая стена, перегородившая продолжение дороги у самого края (на Depot — забор восточного двора поперёк
  северной улицы), открывается на ширину дороги; если она в закреплённом районе — остаётся и отчёт пишет «закрыто замком».
- Маршруты перепроверяются (при поломке — следующий seed), швы проверяются проходом по навигации (`checkSeams`: дорога и канал
  продолжаются, длина пути / прямая ≤ 1,25). Перегенерация зоны на расширенной карте «проигрывает» расширение заново на свежем
  ядре (те же улицы, новые кварталы).
- Скриншоты: `071-levelgen-expand-x4.png` (×4, белым пунктиром — шов старой карты) и `071-levelgen-expand-x4-reroll.png`
  (перегенерирована западная полоса новой площади: 6 кварталов сменили тип, ядро не тронуто).

### D. Старт + 2–4 цели в свободном порядке (`src/levelgen/objectives.ts`)
- Старт — точка появления карты или (выбор) конец улицы у края карты. Цели: на земле, достижимы со старта (заливка навигации),
  ≥ 50 м от старта, ≥ 40 м друг от друга (самая дальняя точка с разбросом по seed), не в закреплённых зданиях (если не разрешено),
  не в канале и не у края. Кандидаты: комнаты первого этажа входимых зданий, дворы, центры улиц. Число по умолчанию по размеру
  карты: 2 / 2 / 3 / 4 (×1 / ×2 / ×4 / ×6), можно 2–4 вручную.
- Хранятся в JSON карты: блок `objectives` (`version`, `seed`, `order: "free"`, `start`, `goals[]`), рисуются на плане (зелёное
  кольцо S, жёлтые круги с номерами). Проверка: старт → каждая цель и цель ↔ цель (любой порядок), кратчайший порядок обхода.
- Скриншот: `071-levelgen-goals.png` (×4, старт у западного края, 3 цели, обход 736 м, мин. расстояние между целями 201 м).

## Как пользоваться в TG («Генератор уровней» → «Генератор раскладок»)
1. «Сгенерировать» или открыть принятую карту.
2. Зона (как на этапе 1): «Рамка» / «Многоугольник» / «Лассо», галочка «новые типы кварталов», seed, «Перегенерировать зону».
   Строка «В зоне» показывает, сколько кварталов сменит тип; после клика — «Новые типы кварталов: … → …».
3. «Закрепить район» → «Сохранить замки» (только замки; «Принять» по-прежнему сохраняет всю карту).
4. Блок «Расширение»: выбрать ×2 / ×4 / ×6 (в списке — размер в метрах), seed, «Расширить карту»; отчёт: улицы, кварталы по
   типам, швы (продолжается / ОБРЫВ), маршруты. Карта переименовывается в `<имя>_x<N>`. «Отменить» возвращает шаг.
5. Блок «Старт и цели»: число (авто / 2 / 3 / 4), старт (точка появления / край карты), seed, «Расставить старт и цели»;
   строка под ним — длины путей до целей и кратчайший обход; «Убрать цели».

## Не сделано / открыто
- **Нужен C++ / сборщик UE:** (1) `objectives` — в игре нет задачи «посетить N целей в любом порядке»: нужно чтение блока
  `objectives` (старт + цели) в LevelJsonRules/миссии и маркеры целей; старт с края сейчас не меняет `spawn` карты.
  (2) `Scripts/Editor/build_levelgen_map.py` (Python) берёт плоскость земли и NavMeshBounds из `bounds` и канал из `cut.poly` /
  `crossings` — должен собрать и расширенную карту, но это не проверено в UE (большие карты + бот — следующий этап по доске).
  (3) Бот/плейтест по целям.
- Каталог типов — универсальные сет-пьесы; классические «руина с проломами» и «сталелитейный цех» в каталог не входят (их можно
  заменить, но не получить обратно перегенерацией). Веса и размеры типов — в `levelgen_v2.json` (дизайнер может настроить).
- Узкие кварталы, куда не помещается другой тип, остаются старого типа (показано в отчёте).
- Вариант маршрута, все точки которого были в сменившемся квартале, заходит в новый квартал или убирается (показано в отчёте).
- Цели, попавшие в перегенерированный квартал, не переставляются сами: строка целей покажет «НЕДОСТИЖИМА» — нажать «Расставить».
- Маршрут, выходящий из зоны и входящий снова, по-прежнему склеивается одним куском (пункт этапа 1).
- Этап 3 («эталон → профиль стиля → новая карта»): заготовка — комментарий в `levelgen_v2.json` (будущий блок `style` будет
  перевешивать `templates.catalog.*.weight`); нужен эталон от дизайнера.
