## 1. Масштаб и сдвиг плана
- **Колесо мыши** — приблизить / отдалить вокруг курсора (точка под курсором остаётся на месте).
- **Сдвиг** — средняя кнопка мыши или **пробел + перетаскивание** в любом инструменте; в режиме «Просмотр» — просто левой кнопкой.
- Над планом: «−», процент масштаба, «+», **«Вписать»** (вся карта целиком). Масштаб 50 %…4000 % (`plan_view` в конфиге).
- Все инструменты (рамка, многоугольник, лассо, старт и цели, проигрыватель) работают при любом масштабе: план и слой
  инструментов пересчитываются через одно и то же преобразование (`src/levelgen/planView.ts`).
- При смене карты (другой размер, расширение) вид сбрасывается на «Вписать».
- Скриншот: `docs/port/screenshots/072-levelgen-zoom.png`.

## 2. Перетаскивание старта
- Зелёное кольцо **S** тянется мышью в режиме «Просмотр» (и в режиме «+ цель»). При отпускании заново проверяются пути от старта
  до каждой цели и между целями, пересчитываются длины и кратчайший порядок обхода (жёлтый пунктир на плане — реальный путь по
  навигации). Источник старта в JSON становится `manual`.
- Недопустимое место (в стене, внутри здания без входа, в канале, за краем карты) — кольцо красное, причина подписана рядом;
  старт остаётся там, куда его бросили (ничего не сдвигается само). Каждый перенос — шаг «Отменить / Вернуть».

## 3. Цели
- «Расставить старт и цели» (авто) работает как раньше.
- Вручную: кнопка **«+ цель»** над планом, затем щелчок по плану — новая цель (если на карте ещё нет целей, старт = точка появления).
  Цель **перетаскивается**; **удалить** — правая кнопка по цели или маленький «×» у цели. Лимиты 1…4
  (`objectives.manual_count_min` .. `count_max`); пятую не добавить, последнюю не удалить (всё убирает «Убрать цели»).
- После каждого изменения: достижимость, длины, кратчайший порядок. **Ошибка** (красная цель + причина): за краем карты, в канале,
  внутри здания без входа, в стене, в закреплённом здании, недостижима со старта. **Внимание** (оранжевая обводка, строка под
  панелью): ближе 50 м к старту, ближе 40 м к другой цели — правила авторасстановки, для ручной не запрет.
- Пока есть ошибки, кнопка «Принять» неактивна (подсказка перечисляет ошибки). Цели сохраняются в блоке `objectives` как раньше.

## 4. Полная перегенерация зоны
**Что было:** флажок «новые типы кварталов» по умолчанию был ВКЛЮЧЁН (режим `types`). Но шаблон типа заполняет весь квартал, поэтому
новое здание стоит там же и почти той же формы, что старое, — отсюда «поменялись только точки и пропсы». Плюс квартал берётся только
когда его ЦЕНТР внутри зоны.

**Что стало:** вместо флажка — список «Что менять» (по умолчанию — новый режим):
- **«Полностью (форма и расстановка)»** — квартал заново делится на участки (разрез всегда оставляет обе части на улице — двери и
  ворота смотрят на улицы), каждый участок получает свой тип из каталога, здание в участке получает свой отступ от улицы, ширину,
  глубину и промежутки до соседей; угловой участок может «повернуться» к другой улице. Ползунок **«хаос»**: 0 — ровная сетка
  (разрезы пополам, здания вровень с улицей), 1 — неровно (разные доли, отступы, зазоры, повороты).
- «Тип квартала (здания на тех же местах)» — прежний режим этапа 2.
- «Только наполнение (укрытия, точки)» — прежний режим этапа 1.

Все прежние правила действуют: закреплённые районы не трогаются (байт в байт), дороги и канал не трогаются, маршрут проходит через
район (визит — ворота / дверь / лестница участка рядом с центром старого квартала), при поломке — повтор с другим seed, высоты —
только измеренные классы, швы расширения как раньше. Участки хранятся в `regen.blocks` с полем `parent` (исходный квартал); при
следующей полной перегенерации все участки квартала, попавшие в зону, переразбиваются вместе. Детерминированно по seed + хаос.
Константы — `full_reroll` в `levelgen_v2.json`. Повороты — только на 90° (к другой улице): схема и сборщик UE знают лишь
прямоугольники по осям.

Числа (Depot seed 1, зона СЗ, 6 кварталов): 4 seed × хаос 0 / 0.5 / 1 — все приняты без повторов, 30–45 мс на клик; число
зданий на карте 12 → 9…17; ни один старый контур здания в переразбитых кварталах не остаётся. На странице (seed 303): хаос 0 —
12 участков, убрано 47 / добавлено 44 объекта; хаос 1 — 11 участков, 47 / 41; маршрут проходим, повторов 0.
Наблюдение: на хаосе 0 мелкие участки часто получают «глухой фасад» и «контору» (веса каталога) — если план покажется слишком
дробным, поднять `full_reroll.split_min_m` / `min_parcel_m` или снизить `split_chance_tidy`.
Скриншоты: `072-levelgen-full-before.png` (зона, голубым пунктиром — кварталы, которые переразобьются), `072-levelgen-full-chaos0.png`
и `072-levelgen-full-chaos1.png` (тот же seed 303).

## 5. Проигрыватель прогона отряда
- «Прогнать отряд (симулятор)» теперь сохраняет траекторию: позиции бойцов 5 раз в секунду (`playback.sample_hz`) по всем наземным
  участкам маршрута на одних часах.
- Под планом — проигрыватель: «Играть / Пауза», скорость x1 / x2 / x4 / x8, ползунок времени, время, номер участка и текущий строй.
  На плане — розовые точки (лидер крупнее) и след лидера за последние 8 с. Сводка: бойцы, длительность, путь лидера, участки, доли
  строёв, углы, раскладки у стены.
- Траектория хранится только на странице (в «Принять» не уходит).
- Ограничение симулятора: он идёт только по земле; крыши, лестницы и этажи пропускаются — точки «перескакивают» между участками.
- Скриншот: `072-levelgen-playback.png` (2:41 из 5:07, x8, приближено к отряду; Depot: 4 бойца, 307 с, лидер 537 м по 2 наземным

## 6. «Собрать в Unreal»
- Кнопка рядом с «Принять», активна для принятой карты. Имя карты — одно правило: `L_Gen_` + имя раскладки без `gen_ref_NN_NN_`,
  слова с заглавной: `gen_ref_01_02_depot_1` → `L_Gen_Depot_1`, `gen_ref_01_02_depot_1_x4` → `L_Gen_Depot_1_X4`
  (`build.strip_prefix`). Правило и итоговый путь показаны в панели «Сборка в Unreal».
- Сервер TG фоном запускает (через `powershell.exe` напрямую, не Git Bash) скрипты СВОЕГО checkout:
  `levelgen_build_map.ps1 -Layout <имя> -Target /Game/Maps/Generated/L_Gen_<Name> -StatusFile Saved/LevelGen/build_<карта>.json`,
  затем `levelgen_route_smoke.ps1 -Map ... -StatusFile Saved/LevelGen/route_<карта>.json`.
- Панель: этап (1/2 сборка, 2/2 проверка маршрута) + время этапа и общее, сообщение скрипта (в т. ч. «ждёт общий замок сборки»);
  итог — собрана ли (акторов), навигация (`Default=… Vehicle=…` из лога NavBake), маршрут PASS / FAIL с итоговой строкой бота
  или причиной; где открыть (`/Game/Maps/Generated/...`, файл `.umap`).
- Защита: цель всегда выводится из имени принятой раскладки (страница не может назвать другую карту); существующая карта
  заменяется только если её level JSON (`levelgen_layout`) указывает на ЭТУ же раскладку — и только после подтверждения в
  панели («Заменить» / «Отмена»); карта из другой раскладки или без level JSON генератора — отказ. Одна сборка за раз (409).
  Если карта на странице изменена после «Принять», панель предупреждает: собирается принятая версия.
- Сборка ~4–6 мин, проверка маршрута ~6–8 мин (x4). Редактор этого checkout должен быть закрыт (иначе скрипт откажет — причина
  будет в панели).
- Скриншот: `072-levelgen-build.png` (Depot: карта уже есть → запрос подтверждения; сборка в скриншоте не запускалась).
